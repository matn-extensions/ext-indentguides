# Indentation Guides

Subtle vertical indent guide lines with active block scope highlighting

## Details
- **Identifier**: `matn.ext.indentguides`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Indentation Guides**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-indentguides
```
